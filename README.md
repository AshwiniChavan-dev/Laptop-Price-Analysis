# Laptop Price Analysis

## Overview
Analyzed laptop product data using Python to understand pricing patterns based on different laptop specifications.

## Objective
To clean, analyze, and visualize laptop data and identify factors associated with laptop prices.

## Tools & Technologies
- Python
- Pandas
- NumPy
- BeautifulSoup
- Matplotlib
- Seaborn

## Project Workflow
1. Web Scraping
2. Data Cleaning
3. Feature Extraction
4. Exploratory Data Analysis
5. Data Visualization

## Dataset
- 984 laptop records were initially scraped.
- After data cleaning and duplicate removal, 538 records were retained for analysis.

## EDA Performed
- Price distribution analysis
- Price vs RAM
- Price vs Storage
- Price vs Brand
- Price vs Processor Family
- Price vs Operating System
- Price vs Display Size
- Correlation analysis

## Key Insights
- RAM showed a strong positive association with laptop price.
- Storage capacity showed a strong positive association with laptop price.
- Display size showed a weaker relationship with price.
- Laptop prices varied considerably across brands and processor families.
